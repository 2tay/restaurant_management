BRIGADE — Installation
Version 1.0.0
======================

Ce dossier contient :
  - Brigade-1.0.0.apk             l'application pour téléphones et tablettes Android
  - Brigade-1.0.0-Windows.zip     l'application pour ordinateurs Windows (64 bits)
  - INSTALLATION.txt              ce document


1. SUR UNE TABLETTE OU UN TÉLÉPHONE ANDROID
-------------------------------------------

1. Copiez le fichier « Brigade-1.0.0.apk » sur l'appareil (câble USB, e-mail,
   Google Drive, WhatsApp…).
2. Ouvrez le fichier sur l'appareil.
3. Android demande d'autoriser l'installation depuis cette source
   (« Sources inconnues ») : appuyez sur « Paramètres », activez
   « Autoriser depuis cette source », puis revenez en arrière.
4. Appuyez sur « Installer », puis sur « Ouvrir ».

L'application « Brigade » apparaît ensuite avec les autres applications.

Si Google Play Protect affiche un avertissement (« application inconnue »),
choisissez « Plus de détails » puis « Installer quand même ». C'est normal pour
une application qui n'est pas distribuée par le Play Store.


2. SUR UN ORDINATEUR WINDOWS
----------------------------

1. Faites un clic droit sur « Brigade-1.0.0-Windows.zip » puis
   « Extraire tout… ». Choisissez un dossier durable, par exemple
   C:\Brigade (pas le dossier Téléchargements).
2. Dans le dossier extrait, double-cliquez sur « Brigade.exe ».
3. Au premier lancement, Windows peut afficher « Windows a protégé votre
   ordinateur » : cliquez sur « Informations complémentaires », puis
   « Exécuter quand même ».
4. Pour la retrouver facilement : clic droit sur « Brigade.exe » →
   « Afficher d'autres options » → « Envoyer vers » → « Bureau (créer un
   raccourci) ».

Ne déplacez pas « Brigade.exe » seul hors de son dossier : il a besoin des
fichiers qui l'accompagnent.


3. PREMIÈRE UTILISATION
-----------------------

Sur le premier appareil :
  - « Créer un compte » avec l'adresse e-mail du propriétaire et un mot de
    passe (8 caractères minimum), puis « Créer le restaurant ».

Sur chaque autre tablette, téléphone ou ordinateur du restaurant :
  - « Se connecter » avec l'adresse e-mail et le mot de passe du propriétaire.
    L'appareil télécharge les données du restaurant, puis s'ouvre.

Ensuite, chaque employé ouvre l'application avec son adresse e-mail et son PIN.

Une connexion Internet est nécessaire pour créer le compte et pour la première
connexion d'un appareil. Ensuite, l'application fonctionne aussi hors ligne et
envoie les modifications dès que la connexion revient.


4. MISES À JOUR
---------------

Android : installez le nouveau fichier .apk par-dessus l'ancien, sans
désinstaller. Les données de l'appareil sont conservées.

Windows : fermez Brigade, remplacez le contenu du dossier (par exemple
C:\Brigade) par celui de la nouvelle version, puis relancez « Brigade.exe ».
Les données sont enregistrées ailleurs et sont conservées.

Attention : désinstaller l'application Android efface les données de cet
appareil qui n'ont pas encore été envoyées.
